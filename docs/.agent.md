# .agent — fiche d'entrée pour agents IA sur RevIA (Revia_PE)

À lire en premier : ce fichier résume l'essentiel et renvoie vers les documents détaillés.

## Projet

| Élément | Valeur |
|---------|--------|
| Nom | RevIA |
| But | Revue de code assistée par IA (score /100, problèmes par gravité, corrections avant/après, OWASP) |
| Dépôt | `Revia_PE`, branche `main` |
| Langue | Français (interface, messages d'erreur, réponses) |
| Équipe | Nafissa Bridah, Rahma Kehrji, Housine Saihi, Aziz Eifa, Mustapha Sifaoui |

## Stack

| Couche | Technologies |
|--------|--------------|
| Frontend | Angular 17.3 (standalone, signals), Angular Material, Monaco, Chart.js, Node 20 |
| Backend | Spring Boot 3.5.16, Java 17, Spring AI 1.1.8, Spring Security 6.5, Bucket4j, jjwt, Flyway |
| Base de données | PostgreSQL 16 (prod / Docker), H2 (dev) |
| LLM | Gemini gratuit (`gemini-flash-lite-latest`) ; autres : groq, ollama, openai, anthropic ; `demo` = sans LLM |

## Environnement

- Fichier `.env` copié depuis `.env.example`, **jamais commité**.
- Obligatoires : `REVIA_JWT_SECRET` (≥ 32 caractères) et `DATABASE_PASSWORD` (identique au `POSTGRES_PASSWORD` de la base).
- Optionnelles : `REVIA_AI_PROVIDER`, `REVIA_AI_MODEL`, `REVIA_AI_API_KEY`, `REVIA_CORS_ORIGINS`, `REVIA_ADMIN_EMAIL`.
- Sans clé Gemini : `REVIA_AI_PROVIDER=demo`.

## Interdits

- Commiter `.env`, des clés API ou de vrais mots de passe.
- Appeler un LLM depuis le navigateur ou exposer `REVIA_AI_API_KEY`.
- Supprimer `MasqueurDonnees`, la validation de `ReponseIA`, `QuotaService`, le JWT ou l'isolation des revues par auteur.
- Afficher le score brut du LLM (le score vient de `Revue.calculerScore()`).
- Exposer une stacktrace au client.
- Commiter, pousser, supprimer un volume ou une branche, ou écraser les modifications locales de l'utilisateur sans demande.

## Pièges connus

- nginx **502** sur `/api/**` = backend en échec : lire `docker compose logs backend` (souvent un mot de passe PostgreSQL différent de `DATABASE_PASSWORD`).
- Le volume PostgreSQL garde le mot de passe de sa première initialisation.
- Toute nouvelle route Angular de premier niveau doit être ajoutée à `SpaController` (mode JAR).
- Le prompt actif est en base : après modification de `revue-system.st`, publier une version en admin ou réinitialiser H2 en dev.
- `gemini-flash-latest` : 20 requêtes par jour seulement.
